 1. Kafka Topic Creation (`bash`):

```bash
# Create sensor-readings topic with 3 replication factors and 10 partitions
kafka-topics.sh --create --topic sensor-readings --partitions 10 --replication-factor 3 --config retention.ms=604800000 --bootstrap-server kafka:9092

# Create sensor-readings-clean topic with 3 replication factors and 10 partitions
kafka-topics.sh --create --topic sensor-readings-clean --partitions 10 --replication-factor 3 --config retention.ms=604800000 --bootstrap-server kafka:9092
```

The replication factor is set to 3 to ensure data durability, and 10 partitions are created to handle the input rate of 50,000 events/s. The retention period is set to 7 days (604800000 ms).

3. Flink SQL `CREATE TABLE` statements:

```sql
-- Sensor readings source table
CREATE TABLE sensor_readings (
    sensor_id BIGINT,
    reading JSON,
    PROPERTIES (
        'connector' = 'kafka',
        'topic' = 'sensor-readings',
        'format' = 'json',
        'json.ignore-parse-errors' = 'false',
        'json.fail-on-missing-field' = 'false',
        'json.ignore-case' = 'true',
        'kafka.bootstrap.servers' = 'kafka:9092'
    )
);

-- Enriched sensor readings table
CREATE TABLE enriched_sensor_readings (
    sensor_id BIGINT,
    reading JSON,
    temperature DOUBLE,
    humidity DOUBLE,
    pressure DOUBLE,
    timestamp TIMESTAMP(3),
    PROPERTIES (
        'connector' = 'table'
    )
);

-- Sensor readings clean sink table
CREATE TABLE sensor_readings_clean (
    sensor_id BIGINT,
    reading JSON,
    temperature DOUBLE,
    humidity DOUBLE,
    pressure DOUBLE,
    timestamp TIMESTAMP(3),
    PROPERTIES (
        'connector' = 'kafka',
        'topic' = 'sensor-readings-clean',
        'format' = 'json',
        'kafka.bootstrap.servers' = 'kafka:9092'
    )
);
```

The source table reads from the `sensor-readings` Kafka topic, and the sink table writes to the `sensor-readings-clean` Kafka topic. The enriched table is an intermediate table that derives the temperature, humidity, and pressure fields from the raw reading JSON. The `json.ignore-parse-errors` and `json.fail-on-missing-field` properties are set to handle malformed events. The `json.ignore-case` property is set to ensure case-insensitive JSON parsing.
