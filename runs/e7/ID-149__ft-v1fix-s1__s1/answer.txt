# 1. `kafka-topics.sh` commands to create all topics
```bash
# create topic 'ad-impressions'
./bin/kafka-topics.sh --create --topic ad-impressions --partitions 4 --replication-factor 3 --config retention.ms=2592000000 --config min.insync.replicas=2 --bootstrap-server kafka:9092

# create topic 'ad-impressions-enriched'
./bin/kafka-topics.sh --create --topic ad-impressions-enriched --partitions 4 --replication-factor 3 --config retention.ms=2592000000 --config min.insync.replicas=2 --bootstrap-server kafka:9092
```
