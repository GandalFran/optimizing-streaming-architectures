 1. Kafka Topic Creation (`bash`):

```bash
# Create clicks topic with 10 partitions, replication factor 3, and 5 MB segment size
kafka-topics.sh --create --topic clicks --partitions 10 --replication-factor 3 --config retention.ms=2592000000 --config compression.type=lz4 --bootstrap-server kafka:9092

# Create clicks-enriched topic with 10 partitions, replication factor 3, and 5 MB segment size
kafka-topics.sh --create --topic clicks-enriched --partitions 10 --replication-factor 3 --config retention.ms=2592000000 --config compression.type=lz4 --bootstrap-server kafka:9092
```

The topic configurations are set to meet the retention requirement of 30 days (2592000000 ms) and use LZ4 compression for better performance and storage efficiency. The number of partitions is chosen based on the input rate and Kafka's throughput capacity.
