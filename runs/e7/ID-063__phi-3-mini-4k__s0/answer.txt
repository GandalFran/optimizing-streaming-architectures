 ```bash
# Create Kafka topics
kafka-topics.sh --bootstrap-server kafka:9092 --create --topic sensor-readings --partitions 3 --replication-factor 3
kafka-topics.sh --bootstrap-server kafka:9092 --create --topic sensor-readings-clean --partitions 3 --replication-factor 3
```

```sql
-- Flink SQL table creation for sensor-readings topic
CREATE TABLE sensor_readings (
  sensor_id STRING,
  event_time TIMESTAMP(3),
  data STRING
) WITH (
  'connector' = 'kafka',
  'topic' = 'sensor-readings',
  'properties.bootstrap.servers' = 'kafka:9092',
  'properties.group.id' = 'sensor-reading-group',
  'properties.key.deserializer' = 'org.apache.kafka.common.serialization.StringDeserializer',
  'properties.value.deserializer' = 'org.apache.kafka.common.serialization.StringDeserializer',
  'format' = 'json'
);

-- Flink SQL table creation for sensor-readings-clean topic
CREATE TABLE sensor_readings_clean (
  sensor_id STRING,
  event_time TIMESTAMP(3),
  data STRING
) WITH (
  'connector' = 'kafka',
  'topic' = 'sensor-readings-clean',
  'properties.bootstrap.servers' = 'kafka:9092',
  'properties.group.id' = 'sensor-reading-group',
  'properties.key.deserializer' = 'org.apache.kafka.common.serialization.StringDeserializer',
  'properties.value.deserializer' = 'org.apache.kafka.common.serialization.StringDeserializer',
  'format' = 'json'
);
```

Justification:
- The Kafka topics are created with 3 partitions each, ensuring that the system can handle the input rate of 50,000 events per second. The replication factor of 3 ensures durability and fault tolerance.
- The Flink configuration is set up for a standalone session cluster with 3 task managers, each with 4 CPU cores and 8 GB of memory. The checkpointing interval is set to 1 second to meet the end-to-end latency requirement. The state backend is configured to use S3 for durable checkpoints.
- The Flink SQL table creation statements define the schema for the input and output Kafka topics. The JSON format is used for both topics. The `event_time` field is included to support event time processing if needed in the future.
