```bash
# Create the ad-impressions topic with 10 partitions and replication factor 3
kafka-topics.sh --create --topic ad-impressions --bootstrap-server kafka:9092 --replication-factor 3 --partitions 10

# Create the ad-impressions-enriched topic with 10 partitions and replication factor 3
kafka-topics.sh --create --topic ad-impressions-enriched --bootstrap-server kafka:9092 --replication-factor 3 --partitions 10
```

```yaml
# Flink configuration
execution.checkpointing.interval: 10s
execution.checkpointing.mode: EXACTLY_ONCE
execution.checkpointing.unaligned: true
execution.checkpointing.min-pause: 1s
execution.checkpointing.timeout: 60s
execution.state.backend: rocksdb
execution.state.checkpoints.dir: s3://flink-state/checkpoints
execution.parallelism: 5
taskmanager.numberOfTaskSlots: 4
```

```sql
-- Create the source table for ad-impressions
CREATE TABLE ad_impressions (
    campaign_id STRING,
    impression_data STRING,
    event_time TIMESTAMP(3) METADATA FROM 'timestamp'
) WITH (
    'connector' = 'kafka',
    'topic' = 'ad-impressions',
    'properties.bootstrap.servers' = 'kafka:9092',
    'format' = 'json',
    'scan.startup.mode' = 'latest-offset',
    'properties.group.id' = 'ad-impressions-group',
    'scan.subtasks' = '5'
);

-- Create the sink table for ad-impressions-enriched
CREATE TABLE ad_impressions_enriched (
    campaign_id STRING,
    impression_data STRING,
    enriched_data STRING,
    event_time TIMESTAMP(3)
) WITH (
    'connector' = 'kafka',
    'topic' = 'ad-impressions-enriched',
    'properties.bootstrap.servers' = 'kafka:9092',
    'format' = 'json',
    'sink.partitioner' = 'round-robin'
);
```

**Justification:**

1. **Kafka Topic Configuration:**
   - **Partitions:** 10 partitions are chosen for each topic to distribute the input rate of 50,000 events/s evenly across the partitions, ensuring that each partition handles up to 5,000 events/s, well within the 20,000 events/s limit per Flink source subtask.
   - **Replication Factor:** 3 to ensure high availability and durability.

2. **Flink Configuration:**
   - **Checkpointing:** Configured for exactly-once semantics with a checkpoint interval of 10 seconds to ensure data consistency and durability.
   - **Parallelism:** Set to 5 to match the number of partitions in the Kafka topic, allowing each subtask to handle one partition.
   - **Task Slots:** Each TaskManager has 4 slots, allowing for efficient parallel execution of the Flink job.

3. **Flink SQL Table Definitions:**
   - **Source Table:** Configured to read from the `ad-impressions` topic with 5 subtasks to match the parallelism.
   - **Sink Table:** Configured to write to the `ad-impressions-enriched` topic using a round-robin partitioner to distribute the output evenly across partitions.
